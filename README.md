# Python Flashcards - Flask App

Pequena aplicação web desenvolvida com Flask que apresenta flashcards de conceitos básicos de programação.

<img width="1366" height="473" alt="image" src="https://github.com/user-attachments/assets/216da140-57e0-418a-a717-1efe5f989f90" />


## Tecnologias utilizadas

- Python
- Flask

## Instalação

Clone o repositório:

git clone <https://github.com/the-abreu/simple-flask-quiz.git>

Instale as dependências:

pip install -r requirements.txt

## Executar a aplicação

python app.py

Abra no navegador:

http://127.0.0.1:5000

## Descrição

A aplicação sorteia perguntas sobre conceitos básicos de programação e exibe suas respostas em formato de flashcards.

## Possíveis melhorias

- Adicionar novos flashcards
- Criar sistema de pontuação
- Permitir adicionar novas perguntas pela interface
